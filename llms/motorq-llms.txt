# Motorq

> Motorq is a connected vehicle intelligence platform that taps native OEM connectivity to deliver AI-powered insights across the automotive ecosystem. It aggregates and normalizes vehicle telematics data from 25+ automotive brands and third-party sources — with no plug-in hardware or dongles — so fleets, fleet management companies, dealerships, lenders, insuretechs, and mobility companies can drive maintenance, safety, utilization, and EV use cases. Access is offered through a fleet portal, bi-directional APIs/data streams, and a Snowflake data lake integration.

## API
> Motorq exposes bi-directional connected-vehicle APIs and data streams (e.g. Get Location, Create Geofence) plus a Snowflake data lake share. Access is gated to enterprise and OEM partners; there is no public developer portal, OpenAPI definition, or self-serve documentation as of this writing. Contact Motorq to request API access.
